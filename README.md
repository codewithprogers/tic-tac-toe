# tic-tac-toe

Create a tic-tac-toe game with as little global code as possible. This project
will use factory functions and the module pattern to organize the gameboard,
players, and game flow.

The goal of this project is to build an interactive tic-tac-toe game where
players can click on a specific square on the gameboard to place their marker,
either "X" or "O". Each square can only hold one marker, and players cannot
place a marker on a square that is already taken.

The game will check for winning combinations across rows, columns, and diagonals.
The first player to get three markers in a row wins the game. The interface will
include a button to start or restart the game, player name inputs, and a display
message that shows the result when the game ends.
